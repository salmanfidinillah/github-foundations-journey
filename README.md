## Key Concepts

### GitHub Issues

GitHub Issues help teams track:

- Bugs
- Feature requests
- Tasks
- Improvements
- Project discussions that require action

### Issue Templates

Issue templates provide predefined structures for reporting bugs and requesting features.

Example directory:

```text
.github/
└── ISSUE_TEMPLATE/
    ├── bug_report.md
    └── feature_request.md
```

### Pull Request Templates

A pull request template helps contributors explain their proposed changes.

Common location:

```text
.github/
└── pull_request_template.md
```

### Automatically Closing Issues

A pull request description can reference an issue using a closing keyword.

Example:

```text
Fixes #12
Closes #15
Resolves #18
```

When a pull request targeting the repository's default branch is merged, supported closing keywords can automatically close the referenced issues.

## Key Concepts

### GitHub Discussions

GitHub Discussions provides a space for conversations, questions, announcements, and community ideas.

### Discussion Categories

| Category | Purpose |
|---|---|
| General | General conversations |
| Ideas | Feature suggestions |
| Q&A | Questions and answers |
| Announcements | Official announcements |
| Polls | Community voting |

### Discussions vs Issues vs Pull Requests

| Feature | Purpose |
|---|---|
| Discussions | Community conversations |
| Issues | Tracking bugs and tasks |
| Pull Requests | Reviewing and merging code changes |

### GitHub Notifications

Notifications help developers follow repository activity and participate in conversations.

### Watch vs Star vs Fork

- **Watch:** Subscribe to repository notifications.
- **Star:** Bookmark or show appreciation for a repository.
- **Fork:** Create a copy of a repository under another account.

## Community Documentation

Important repository files include:

```text
README.md
CONTRIBUTING.md
CODE_OF_CONDUCT.md
SECURITY.md
LICENSE
```

### CONTRIBUTING.md

Provides instructions for contributors.

### CODE_OF_CONDUCT.md

Defines expected community behavior.

### SECURITY.md

Explains how to report security vulnerabilities.

### LICENSE

Defines the legal terms for using and distributing the project.
